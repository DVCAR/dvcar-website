# DVC Autonomous Racing

A student club at Diablo Valley College building a self-driving electric
go-kart to compete in the [Autonomous Karting Series](https://autonomouskarting.com)
at Purdue in May 2027.

## This repo

Source for the club website. Just getting started.

## Teams

- **Electrical**: drive-by-wire (steering, brake, throttle), power
  distribution, remote e-stop, sensor integration
- **Mechanical**: chassis, drivetrain, steering and braking hardware,
  fabrication
- **Software**: autonomy stack, perception, tooling, and this website
- **Business**: funding, sponsorship, outreach, and our YouTube channel
